    遊びの流れ

    1. キャラ作成:名前・性別・種族・好きな漢字・好きな色・生年月日を入れると、キャラが生まれます。
    2. 保存:気に入ったら「このキャラを保存」。キャラ一覧とバトルで使えます。
    3. バトル:「闘技場」「トーナメント」「アーケード」から選びます。闘技場は1Pと2Pのキャラと武器を選んで「対戦開始」。戦いは自動で進みます。

    同じ入力からは、いつでも同じキャラが生まれます。友だちと同じ入力をすれば、同じキャラで戦えます。

    キャラ作成

    種族
    ベオク(人間)は武器を2〜4本持ちます。ラグズは獣・鳥・竜に化身する種族で、武器は爪などの1つだけです。
    好きな色
    色に合う職業が出やすくなります(赤=剣・竜、青=槍、緑=斧・虎、黄=光・軽器・猫、白=弓・飛行・タカ、黒=軽器・重装・カラス、紫=魔法、橙=騎馬)。
    好きな漢字
    成長の傾向(力型・速さ型など)が決まります。得意な能力は成長率+15、苦手な能力は-5。
    生年月日
    誕生月で属性が決まります(下の「属性」)。誕生日で幸運が少し変わります。
    空欄をランダムで生み出す
    入力していない項目だけをランダムに決めて生み出します。全部空欄なら、全部ランダムです。

    ベオクはLv20、ラグズはLv10まで育った状態で生まれます。レベルアップ演出はスイッチで消せます。

    キャラ一覧

    • 能力値の表の「ボーナス」は、そのキャラだけの成長率の上乗せ(職業の成長率との差)です。緑はプラス、赤はマイナス。
    • キャラはこのブラウザに保存されます。書き出し(JSON)でファイルにしておくと、別のPC・スマホに持っていけます。
    • 読み込み(JSON)では、ファイルの中のキャラが「新しいキャラ」「登録済み」に分かれて表示され、新しいキャラだけを読み込めます。キャラには入力から決まるIDがあり、同じキャラが2体になることはありません。
    • 並び順は「新着」「クラス順」、またはクラスを指定して絞り込めます。

    バトル準備

    • 1P・2Pのキャラと、その対戦で使う武器を選びます。▲は3すくみ有利、▼は不利、⚠特効は相手に特効がある武器です。
    • バイオリズムは対戦ごとに変わります。好調=命中・回避+10・必殺+5、不調=命中・回避-10。
    • 真ん中の戦闘予測で、威力・命中・必殺・攻速を確かめられます。「×2」は1ラウンドに2回攻撃するという意味です。
    • ラグズは「化身前/化身後」のスイッチで、それぞれの能力値と予測を見られます。
    • オプション:1〜3本先取、スキル抽選のON/OFF、抽選の演出のON/OFF(演出はタップで飛ばせます)。
    • スキル選択をONにすると、好きなスキルを1つ選んで戦えます(このときスキル抽選と抽選の演出はありません)。

    トーナメント

    • 8〜16人で戦い、優勝から最下位まで全員の順位を決めます。勝っても負けても次の試合があります(勝った人どうし・負けた人どうしで当たります)。8人なら3試合、9〜16人なら4試合。
    • 出られるキャラが8人以上いると選べます。キャラを何人か選び、残りをランダムで選ぶこともできます(同じキャラは2回選ばれません)。16人に足りないときは、不戦勝の試合があります。
    • 1本先取・2本先取を選べます。引き分けのときは、残りHPの割合が多いほうの判定勝ちです。
    • スキルは毎回ランダム(試合ごとに抽選)か、最初に決めて持ち越し。持ち越しでは、勝ったキャラが相手のスキルと交換できます(自分の前のスキルは相手へ)。
    • 試合の前にバトル準備で武器を選べます。結果だけ見る(おまかせ)で、演出なしですぐに結果を出すこともできます。途中でやめても、続きから遊べます。

    アーケード

    • キャラを1人選んで、11連戦を勝ち抜くモードです。敵はランダムに生まれたキャラです(キャラ一覧には入りません)。
    • 自分のキャラはLv1から始まり、敵を倒すたびにレベルが2つ上がります(ラグズはもともと強いので、Lv1のまま進み、6勝目から2つずつ上がります)。Lv21になるところで上級職にクラスチェンジします。
    • 敵はLv2から2つずつ強くなり、5体目からスキルを使い、8体目からは上級職です。11体目(EXTRA)は赤竜のイナ(回復・祈り・地の祝福)。
    • スキルは毎回ルーレットか最初に選んで持ち越し。持ち越しでは、最初に2つから1つを選び、勝つたびに「ランダムの2つ」か「倒した敵のスキル」と交換できます(交換しなくてもよい)。10体目を倒したときだけ、交換ではなく2つ目のスキルとして追加できます。
    • 負けてもコンティニューできます(イナ戦は3回まで)。10体目を倒すとキャラの名前に★、イナを倒すと★★が付きます。途中でやめても、続きから遊べます。

    バトルのルール

    ラウンド
    1ラウンドで先攻 → 後攻の順に1回ずつ攻撃します。攻速が相手より4以上高いと、もう1回攻撃(追撃)します。どちらかのHPが0になったら決着です。
    先攻・後攻
    1ラウンド目はルーレット、2ラウンド目は逆、あとは交互です。シャドウエッジ・スキル『待ち伏せ』を持っていると毎ラウンド先攻。
    ダメージ
    (攻撃力 − 守備)。攻撃力 = 力 + 武器の威力。魔法は魔力で攻撃し、相手は魔防で受けます。特効なら(攻撃力 − 守備)が2倍、必殺ならダメージ3倍。
    攻速
    速さ − 武器が重すぎる分(重さ − 力。魔導書は重さ − 速さ)。
    命中・必殺
    命中 = 武器の命中 + 技×2 + 幸運、相手の回避 = 攻速×2 + 幸運。必殺 = 武器の必殺 + 技÷2 − 相手の幸運。
    3すくみ
    剣 → 斧 → 槍 → 剣、炎 → 風 → 雷 → 炎。有利なら命中+10・威力+1、不利なら逆。
    属性
    誕生月で決まります。炎(攻撃+2・命中+10)、水(攻撃+2・防御+2)、風(命中・回避+10)、雷(回避+10・防御+2)、光(命中+10・防御+2)、闇(攻撃+2・回避+10)、天(命中+18)、地(回避+15)。
    属性の不利
    炎は水に、水は雷に、雷は風に、風は炎に弱く、光と闇はお互いに弱い(天・地は弱点なし)。不利な側は属性の補正がなくなります(「不利」の印)。
    引き分け
    60ラウンドで決着がつかないか、10ラウンド続けてお互いのHPが減らないと引き分けです。

    N本先取では、2試合目からは前の試合で後攻だったキャラが先攻です。お互いあと1勝(1-1、2-2)になると「最終試合」になります。

    スキル

    • 対戦のはじめに、ルーレットで1人1つスキルが決まります(OFFにもできます)。多くは技の数値%の確率で発動します。
    • スキルの色:紫抽選のスキル、緑の枠武器についたスキル、オレンジ兵種スキル(剣士・ソードマスター・アーチャー・スナイパーの必殺+5、魔道士(炎特化・男)の俊足)。
    • 『流星』『天空』などの奥義は、発動すると大きな演出が出ます。『女神の加護』はめったに出ないレアスキルです。
    • 『見切り』は相手のスキルを、『能力勝負』はお互いのスキルとバイオリズムを無効にします。
    • 『ぶちかまし』(体格×1.5%で、攻撃のあとに体格分のダメージをもう一撃)、『エリート』(ベオクだけ。開幕に上級職になって戦う)、『大器晩成』(4ラウンド目から体格以外の能力値+3)、『地の祝福』(ラウンドのはじめに状態異常と下がった能力を元に戻す)。
    • 武器スキルと同じスキルは、抽選に出ません。

    ラグズと化身

    • ラグズは化身前で始まります。化身前は爪・くちばし・ブレスの威力が0です。
    • 化身ゲージが20になると、その場で化身して大きく強くなります。初期値は幸運(タカ+6・カラス+8・猫+2)。
    • 化身前はラウンドごとに+4、ダメージを受けるたびに+3。化身中はラウンドの終わりに-5され、0で化身が解けます(また溜まります)。
    • 弓・風魔法は鳥(タカ・カラス)に、ラグズ○○などの武器はラグズに特効です。

    武器と錬成

    • ★はレア度です。★が多いほど出にくく、強い武器が多くなります。
    • 錬成:てつ・はがね・細身・どくの武器、手槍・手斧、ファイアー・サンダー・ウインド・ナイフ・ダガーのうち1本が錬成されていることがあります。錬成された武器は名前と数値が緑になり、「錬成 威+1 命+7」のように中身が出ます。★3以上の武器を持っているキャラには付きません。
    • 手斧・手槍などは、ダメージを与えると相手の速さ-1(重なります)。ポイズン・燃焼は毎ラウンドHPが減ります。
    • 武器の説明は、武器の下に短く書いてあります。マウスを乗せると、もっと詳しい説明が出るものもあります。

    ヒント

    • バトル中は「速度:はやい」で2倍速、「結果まで飛ばす」ですぐに結果が見られます。
    • 「スキルそのままでもう一度」で、同じスキルのまま何度も試せます。
    • スマホでは、バトル準備・バトルは横向きで遊んでください。
